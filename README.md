# Grand Exchange

Static one-page site (Hebrew, RTL) for Grand Exchange — currency exchange and international transfers.

- `index.html` — the whole page (styles and scripts inline)
- `logo.png` — logo

No build step. Deploy the folder as-is (e.g. import the repo in Vercel with framework preset "Other").

Still placeholder: the bracketed details (licence number, phone, address, hours, legal disclosure). The contact form is not wired to anything yet. The page is marked `noindex`.
